# Считалочка — математика для детей

Веб-приложение (PWA) для изучения основ математики. Работает в любом браузере на телефоне, планшете и компьютере, ставится на домашний экран и после первого запуска работает без интернета.

Шесть островов-уровней по карте навыков M01–M23 и возрастной карте проекта, 49 миссий, от дошкольников (4–5 лет) до 3 класса. Миссии N09–N33 добавлены по учебникам NCERT (Joyful Mathematics 1, Maths Mela 3): заимствованы методика и механики, тексты и картинки свои.

## Уровни

| Остров | Возраст | Миссии | Навыки |
| --- | --- | --- | --- |
| 1. Остров счёта | примерно 4–5 лет | А01 Чашка каждому, А02 Собери четыре, N01 Цифра и количество, N02 Где больше?; дополнительно N09 Где котёнок?, N10 Разложи по корзинам, N11 Продолжи бусы, N12 Точки на карточке, N13 Пуговицы и ноль | M01–M04, M15, M16 |
| 2. Остров состава | примерно 5–6 лет | А03 Пять мест, N03 Под салфеткой, А04 Посылки; N04 Фигуры (параллельная ветка); дополнительно N14 Пары на пальцах, N15 Длиннее и тяжелее, N16 Утро, день, вечер | M05, M06, M08, M17, M18 |
| 3. Остров десятка | примерно 6–7 лет | N05 Полный десяток, N06 Через десяток, N07 Десятки и единицы; дополнительно N17 Бусы до 100, N18 Сотенная таблица, N19 Монеты, N20 Сколько чего? | M06, M07, M19, M20 |
| 4. Остров групп | примерно 6–8 лет | А05 Одинаковые коробки, А06 Запись для коробок, А11 Поверни сад, N08 Раздели поровну; дополнительно N21 Сколько групп?, N22 Прыжки по прямой, N23 Половина и четверть, N24 Мерки | M09–M11, M13, M17, M22 |
| 5. Остров таблицы | примерно 7–9 лет | T02, T05, T01, T04, T03, T09, T06, T78 (таблица через связи фактов), S01 Задачи | M12, M14 |
| 6. Остров сотен | примерно 8–9 лет | N25 Дополни до 100, N26 Сотни, десятки, единицы, N27 Угадай число, N28 Больше или меньше, N29 Прыжками по прямой, N30 Задача на полоске; дополнительно N31 Симметрия, N32 Часы и календарь, N33 Метр, литр, килограмм | M06, M14, M18, M21, M23 |

- Следующий остров открывается, когда пройдены основные миссии предыдущего (`core` в `src/content/levels.ts`). Геометрия не блокирует путь.
- Внутри острова миссии идут по предпосылкам (`requires`). Дополнительные миссии (N09–N24, N31–N33) не входят в `core`: они расширяют остров и не задерживают переход дальше.
- Взрослый может выбрать стартовый остров для ребёнка, который уже это умеет: принцип «учить с того уровня, где ребёнок сейчас». Предыдущие острова остаются для повторения.
- Таблица умножения идёт не по порядку столбиков, а по стратегиям: ×2 → ×5 и ×10 → ×1 и ×0 → ×4 (удвоение удвоения) → ×3 → ×9 (10 без одной группы) → ×6 (5 и ещё группа) → ×7 и ×8. Запись a × b читается «по a, b раз».
- В задачах (S01) ребёнок сначала выбирает действие, затем находит ответ, чтобы было видно, где именно ошибка.

## Свои рисунки

Файл в `src/assets/art/` заменяет картинку OpenMoji во всём приложении. Имя — латинское имя предмета из `src/content/art.ts` (`apple.png`, `cat.png`) или код OpenMoji (`1F34E.png`). Подходят PNG, WebP и SVG: сейчас растр, потом вектор с теми же именами, код не меняется. Требования к PNG — в `src/assets/art/README.md`.

## Как устроено обучение

- Каждая миссия: обучение (вариант A), затем самостоятельная проба (B). Повтор (C) открывается позже: через 1, 3, 7 и 14 дней после самостоятельного успеха.
- Длина захода зависит от острова (`length` в `src/content/levels.ts`): 7 карточек на островах 4–6 лет, 8 на островах 6–8 лет, 9–10 на острове таблицы. Повтор короче: 4–5 карточек.
- Сначала идут авторские карточки, остальные строит генератор (`src/content/generate.ts`) по их образцу и в их диапазоне чисел, поэтому сложность сама не растёт, а при каждом входе числа и предметы новые. Подряд одна и та же карточка не повторяется.
- В конце миссии кнопка «Ещё разок» даёт новый набор самостоятельных карточек без обучения. Ребёнок, которому интересно, играет дальше; уставший уходит на карту.
- Помощь по ступеням: 1 — наводящий вопрос, 2 — модель (подсветка, подписи), 3 — разобранный пример. После двух ошибок подряд помощь предлагается сама. Успех после помощи не считается самостоятельным.
- Статусы навыка: знакомится → с помощью → есть самостоятельный успех → уверенно (3 самостоятельных успеха в 2 разных дня) → подтверждено после паузы. Пороги — рабочие настройки пилота (`src/engine/progress.ts`).
- Без таймеров, «жизней», рейтингов и наказания за пропуск дня. Награда — наклейка за пройденную миссию.
- Раздел «Для взрослых» закрыт примером на умножение: отчёт по навыкам словами, история попыток с отметкой помощи, игры для дома, настройки.
- Данные хранятся только в браузере (localStorage), без регистрации.

## Озвучка

Все фразы Счётика заранее записаны одним голосом (Qwen3-TTS, Apache-2.0) и лежат в `public/voice/<голос>/<ключ>.ogg`;
список — `src/audio/voice-keys.json`. Синтез речи устройства не используется: генератор карточек берёт только
озвученные карточки. Конвейер (извлечение фраз, числа в словах с падежами, генерация, проверка Whisper,
замена на запись диктора) — `docs/VOICE_PIPELINE.md`; сравнение голосов — `docs/voice-samples/index.html`.

## Анимации

События игры → состояния Счётика, движение, звуки: `docs/MOTION_SYSTEM.md`. Уровни анимаций и звук настраиваются
в разделе «Для взрослых», системное «Убрать анимацию» уважается всегда.

## Запуск

```bash
npm install
npm run dev       # разработка, http://localhost:5173
npm test          # тесты движка и контента
npm run build     # сборка в dist/
npm run preview   # проверка собранной версии (включая офлайн)
```

## Android

Та же сборка в приложении Capacitor 8 (`android/`), полностью офлайн, без разрешений. Нужны JDK 21 и Android SDK 36.

```bash
npm run build && npx cap sync android
cd android && ./gradlew assembleDebug   # app/build/outputs/apk/debug/app-debug.apk
```

Проверка всех миссий на эмуляторе — `docs/android-qa.md`, подпись релиза — `docs/release-signing.md`.

После слияния в `main` GitHub Actions прогоняет тесты, собирает приложение и кладёт сборку в ветку `gh-pages`, откуда её публикует GitHub Pages.

## Структура

```
src/engine/    прогресс, статусы навыков, расписание повторов, хранение (чистый TS + тесты)
src/content/   карта навыков M01–M23, миссии с вариантами A/B/C и помощью, острова-уровни
src/games/     игровая механика каждой миссии
src/screens/   экраны: профили, карта, миссия, альбом, раздел для взрослых
src/audio/     голос (только записи) и короткие звуки
src/motion/    события игры, состояния Счётика, анимации
tts/           конвейер озвучки (Python)
scripts/       извлечение фраз, проверки на Android
public/        манифест PWA, service worker, картинки OpenMoji и их лицензия
```

## Что дальше

- Прослушать записанную озвучку; при желании перезаписать живым диктором по `public/audio/phrases.tsv`.
- Методист проверяет формулировки, числа и помощь в миссиях.
- Заменить временные картинки OpenMoji на собственную графику (положить файлы в `src/assets/art/`).

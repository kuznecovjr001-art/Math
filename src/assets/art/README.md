# Свои рисунки

Файл, положенный сюда, заменяет картинку OpenMoji во всём приложении.

- Имя — латинское имя предмета из `src/content/art.ts` (`apple.png`, `cat.png`) или код OpenMoji (`1F34E.png`).
- PNG с прозрачным фоном: предмет 512 × 512 px, персонаж и сцена 1024 px по длинной стороне, sRGB.
- Позже можно положить SVG или WebP с тем же именем и удалить PNG: код менять не нужно.

После добавления файла: `npm run build`.

## Иконки и фоны из ТЗ на графику

- `ui/icon-home`, `ui/icon-sound`, `ui/icon-help`, `ui/icon-back`, `ui/icon-lock`, `ui/icon-plus`, `ui/icon-erase` заменяют нарисованные в коде иконки кнопок.
- `bg/<имя>-land` и `bg/<имя>-port` — фон для планшета и телефона. Сейчас подхватываются `world` (вся карта) и карты островов: `map`, `map-compose`, `map-ten`, `map-groups`, `map-table`. Если есть только один вариант, он идёт на оба экрана.

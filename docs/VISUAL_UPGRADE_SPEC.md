# ТЗ: визуал «Считалочки» на высшем уровне

> **Обновлено 2026-10-27:** рисунки для генерации — по `docs/ART_GENERAL_ASSIGNMENT.md` (вектор + анимация).
> Интерфейс, весы, часы, бусы, линейки, числовую прямую и эффекты рисую я сам в SVG; фоны остаются растровыми,
> их чёткость поднимаю апскейлом. Этот документ — обоснование и замеры.

Цель — чтобы приложение выглядело как интерактивный мультфильм: чёткая картинка на любом экране, живой персонаж,
живые острова, единый стиль без случайных чужих значков. Стиль менять не нужно: комплект «Остров счёта»
(акварельно-мультяшный, тёплые цвета, мягкие контуры) хороший и узнаваемый. Нужны **чёткость, слои и полнота**.

## 1. Решения владельца (до начала)

1. **Кто рисует.** (а) генератор изображений (ChatGPT/др.) по этому ТЗ с ручной доводкой; (б) художник;
   (в) смешанно: фоны и предметы — генератор, Счётик и UI — художник. Рекомендую **(в)**: у генератора хорошо
   получаются фоны и предметы, но слои персонажа с точными шарнирами и единый UI-набор он делает плохо.
2. **Анимация Счётика.**
   - **Rive** (рекомендую для «высшего качества»): аниматор собирает в редакторе Rive скелет, мимику и состояния,
     отдаёт один файл `.riv`. Деформации, плавные переходы, синхронизация рта с голосом. Рантайм ~150 КБ.
   - **Слои PNG/SVG**: художник отдаёт части по слоям, анимацию собираю я в коде. Дешевле, но потолок ниже
     (без деформаций тела).
3. **Размер APK.** Фоны в высоком разрешении добавят ~25–35 МБ (сейчас приложение ~25 МБ + голос ~140 МБ).
   Нормально для RuStore; если важен размер — фоны можно отдавать в двух чёткостях.

## 2. Общие требования ко всем файлам

- PNG, 8 бит, sRGB; у предметов и персонажа — прозрачный фон (RGBA), у фонов — без прозрачности.
- Стиль: как в комплекте «Остров счёта» (`Ostrov_Scheta_Raster/SPEC_RU.md`): мягкий тёмно-коричневый контур
  (не чёрный), тёплая палитра, свет слева сверху, без фотореализма и градиентов «как в 3D».
- **Без текста, цифр и букв внутри картинок** (всё озвучивается и подписывается кодом).
- Без чужих персонажей, логотипов, брендов; лица без пугающих выражений.
- Отступ от края у предметов и персонажа — 4–6 % холста; объект по центру; нижняя точка — на одной линии у серий.
- Тени: мягкая контактная тень под объектом допустима, если она одинаковая во всей серии; отдельной слоем — лучше.
- Имена файлов — латиницей, строчными, через дефис, как в таблицах ниже.
- Права: владелец подтверждает, что может использовать изображения коммерчески (условия генератора/договор с художником).

## 3. Пакеты работ (по приоритету)

### 3.1 P0. Фоны высокой чёткости — 27 сцен × 2 ориентации

Сцены (имена файлов `bg/<имя>-land.png` и `bg/<имя>-port.png`):
`album bakery classroom finish forest garden-plot library meadow orchard packing parent picnic profiles shapes shop
station table tea warehouse workshop world` + карты островов `map map-compose map-ten map-groups map-table map-hundreds`.

| Тип | Ландшафт | Портрет | Безопасная зона |
| --- | --- | --- | --- |
| Сцены миссий и экранов | **3200×2000** (16:10) | **1600×3200** (1:2) | важное — в центральных 70 % по ширине и 80 % по высоте: края обрезаются на разных экранах |
| Карты островов | **3072×2048** (3:2) | **2048×3072** (2:3) | вся картинка видна (карта не обрезается) |

Для сцен миссий: центр кадра — «пол» и спокойный фон, где лежит игровое поле. Яркие детали — по краям и в верхней
трети, они не должны спорить с предметами задания.

**Карты островов — дополнительно слои** (тот же размер, отдельные PNG с прозрачностью):

| Слой | Файл | Зачем |
| --- | --- | --- |
| Основа без облаков и без бликов воды | `map-<остров>-<ориентация>.png` | неподвижная основа |
| Вода (только море, белая маска) | `map-<…>-water-mask.png` | мягкая рябь и блики только на воде |
| Облака (2–4 отдельных облака, каждое — отдельный файл) | `cloud-1.png` … `cloud-4.png`, ~800×400 | облака плывут |
| Кроны деревьев и кусты переднего плана | `map-<…>-foliage.png` | лёгкое покачивание |
| **Метки площадок** | `map-<…>-markers.png` | красные круги **#FF0000** Ø 40 px в центре каждой площадки миссии, без других красных пикселей. Положение камней я считаю отсюда автоматически |

Площадки миссий: столько же и в том же порядке по тропинке, как сейчас (9/7/7/8/9/9 по островам).
Если генератор перерисует карту по-своему — не страшно: по слою меток я переставлю камни.

### 3.2 P0. Счётик для анимации

Общее: холст **2048×2048**, персонаж в той же внешности (черепашка, оранжевый платок, сумка), стоит на линии
y = 1900, анфас с лёгким поворотом 3/4. Образец — текущие `guide-*.png` и `char/guide-sheet.png`.

**Вариант Rive (рекомендую):** файл `schetik.riv`.

- Состояние-машина с входом `mood` (строка): `idle, greeting, listening, thinking, speaking, helping, happy,
  encourage, pointing, celebrating, sleeping` — поведение каждого в `docs/MOTION_SYSTEM.md`.
- Триггер `blink`; вход `talk` (0…1) — открытость рта для синхронизации с голосом.
- Idle: дыхание 4 с, моргание каждые 3–6 с; переходы между состояниями 150–300 мс, без рывков.
- Без звука внутри файла; фон прозрачный.

**Вариант слоями** (PSD/KRA или SVG с группами), каждая часть — отдельный слой с подложкой под стыком
(чтобы при повороте не было дыр):

| Слой | Точка вращения | Состояния / кадры |
| --- | --- | --- |
| `shell` панцирь, `body` тело | низ тела | — |
| `leg-l`, `leg-r` | бедро | — |
| `arm-l`, `arm-r` (плечо–локоть), `hand-l`, `hand-r` | плечо, запястье | кисть: открытая, указательный жест, кулачок |
| `head` | основание шеи | — |
| `eye-l`, `eye-r` + `lid-l`, `lid-r` | центр глаза / верх века | веки: открыто, полу, закрыто |
| `brow-l`, `brow-r` | середина брови | нейтральная, радость, раздумье |
| `mouth` | центр рта | 6 форм: закрыт, улыбка, «А», «О», «У», «М/П/Б» |
| `cheek-l`, `cheek-r` | — | румянец (вкл/выкл) |
| `scarf` платок | узел | 2 кадра развевания |
| `bag` сумка | ремень у плеча | — |

Плюс три **недостающие позы** целиком (для варианта слоями и как образец аниматору): `guide-wave` (машет),
`guide-sleep` (дремлет, глаза закрыты), `guide-cheer` (празднует, прыжок).

### 3.3 P1. Недостающие предметы (сейчас OpenMoji) — 15 шт.

1024×1024 RGBA, в стиле комплекта: `ribbon` (бантик), `gift` (подарок), `shirt` (рубашка), `hundred` (табличка
«сотня» — **без цифр**, например мешочек или стопка из 10 десятков), `calendar` (листок календаря без цифр),
`book` (книга), `books` (стопка книг), `clock` (будильник), `bath` (ванна), `thinking` (задумчивое лицо —
лучше **Счётик с лапкой у подбородка**), `potatoes` (картошка), `scarf` (шарф), `abacus` (счёты), `brick`
(кирпичик), `coin` (монета без номинала). Имена файлов — как в скобках: `item/<имя>.png`.

### 3.5 P1. Набор интерфейса (UI-kit)

Чтобы игровые элементы выглядели частью мультфильма, а не веб-формы. Каждый элемент — **3 состояния**: обычное,
нажатое, неактивное; растягиваемые — «девять частей» (углы не тянутся, середина тянется) или SVG.

| Элемент | Файлы | Размер исходника |

| Облачко задания и облачко подсказки | `bubble-task.png`, `bubble-hint.png` (с хвостиком к Счётику слева) | 1200×400, углы 120 px |

## 4. Как передать

```
art-hq/
  bg/            map-land.png, map-land-water-mask.png, map-ten-port-markers.png, ..., meadow-port.png
  clouds/        cloud-1.png ...
  char/          schetik.riv  (или schetik.psd / schetik/*.svg), guide-wave.png, guide-sleep.png, guide-cheer.png
  item/          ribbon.png ... hand-left-0.png ... scales-beam.png ...
  ui/            btn-primary-normal.png ...
  fx/            fx-sparkle-1.png ...
  LICENSE.txt    чем сделано и подтверждение прав
```

Можно партиями: сначала **3.1 + 3.2**, это даёт самый заметный результат.

**Приёмка партии** (проверю автоматически и глазами): размеры и прозрачность по таблицам; нет текста в картинках;
персонаж похож на себя во всех частях; стыки слоёв без дыр при повороте ±20°; метки площадок читаются;
скриншоты всех 49 миссий на телефоне и планшете без обрезания важного.

## 5. Что сделаю я

**После получения:**
1. Конвейер ассетов: из PNG — WebP/AVIF в 1× и 2× (`srcset`), телефон получает свою чёткость, проверка размеров и
   прозрачности, отчёт о весе.
2. Счётик: подключение `.riv` (или сборка рига из слоёв), синхронизация рта с голосом, все состояния из
   диспетчера; на слабых телефонах — упрощённый режим.
3. Острова: рябь по маске воды, плывущие облака, покачивание крон, камни по меткам; пауза при прокрутке и в фоне.
4. UI-набор в кнопках, плитках, облачках, прогрессе; проверка контраста и целей касания ≥ 48 px.
5. Замена фигур из кода рисунками (руки, бусы, весы, часы, линейка, палочки, числовая прямая).
6. Регрессия: 49 миссий × телефон/планшет (Playwright и эмулятор), производительность (кадры, память, размер APK).

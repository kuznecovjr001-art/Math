# Конвейер озвучки Счётика

Цель — один естественный голос во всех фразах, полностью офлайн, без синтеза речи на устройстве.

## Решение

| Вариант | Лицензия | Итог |
| --- | --- | --- |
| **Qwen3-TTS 1.7B** (VoiceDesign → клон-промпт на Base) | Apache-2.0 (код и веса), ограничений на сгенерированное аудио нет | **основной**: голос задаётся описанием, один голос на весь корпус, русский поддерживается |
| Chatterbox Multilingual | MIT, неслышимый водяной знак | запасной |
| Yandex SpeechKit / SaluteSpeech | платно, условия распространения аудио не проверены | запасной, решение владельца |
| Silero, XTTS-v2, Fish, Piper ruslan | некоммерческие | нельзя |
| Piper irina (прежний голос) | лицензия данных не определена | заменён |
| Живой диктор | договор с диктором | эталон; подключается без правки кода (ниже) |

Голоса реальных людей не клонируются: референс голоса синтезирован VoiceDesign по текстовому описанию.

### Три голоса для сравнения

| Голос | Описание | Тон (медиана) | Темп | Whisper |

Единственное «расхождение» у всех — «Счётик» распознан как «Щётик»: так слово и произносится.
A выбран как самый спокойный и потому, что Счётик в текстах говорит о себе в мужском роде («Я задумал число»);
для C пришлось бы менять формы глаголов.

Образцы для прослушивания — в «Загрузки/Schitalochka-golos-Schetika». Корпус пишется заново этим голосом;

Похвала и поддержка звучат разными фразами без повтора подряд (`PRAISE`, `SUPPORT`, `pickPhrase` в

### 1. Фразы (`scripts/voice-extract.ts`)

Постоянные фразы, похвала, финал, три ступени помощи, авторские карточки и подсказки к ним, плюс сгенерированные
карточки и подсказки (сиды 1…5000 во всех режимах). 14 557 фраз (~784 тыс. символов, ~16–17 ч речи). Набор почти
насыщен: каждые новые сиды дают всё меньше фраз. Ключ — `phraseKey(voiceText(текст))`, как в приложении:
повторы удаляются, совпадение ключей разных текстов — ошибка сборки.

### 2. Числа и падежи (`tts/normalize_ru.py`)

Синтезатор получает слова, а не цифры: «в шести коробках», «до ста», «одна единица», «по две ягоды».
Падеж — по предлогу («до/от/из» — родительный, «в» без существительного — предложный, «не хватает» —
родительный), по падежу следующего существительного; род 1 и 2 — по существительному или по последнему
посчитанному предмету фразы. Самопроверка: `python tts/normalize_ru.py` (14 примеров). Отдельные слова с
трудным ударением — `tts/stress.json`: слово (или пара слов, если ударение зависит от смысла: «число стоИт», но
«мяч стОит») → то же слово с ударной гласной заглавной буквой («сравнИ»). Проверено на слух (2026-10-28): знак ´ и
«+» модель не слушает, заглавную гласную — слушает. Слова для словаря находит человек на странице
`docs/voice-samples/stress-check.html` (`python tts/stress_page.py <голос>`: каждое слово корпуса с отрывком).
Если ударение «плавает» и заглавная не помогает («прЫгай»), постоянная часть фразы озвучивается отдельной
проверенной записью: `FIXED_TAILS` в `src/content/missions.ts` + файл в `tts/human/`.

### 3. Сборка (`tts/build_voice.py`)

- Один голос на весь корпус: сохранённый клон-промпт `tts/voices/<голос>.pt`.
- Тишина по краям срезается, громкость выравнивается, Ogg Opus ~19 кбит/с (корпус e-schetik-soft: 14 574 фразы, ~216 МБ).
- Подозрительная длительность (вне 6–22 символов в секунду) попадает в `tts/out/build-report.json`.
- Прерывание безопасно: готовые файлы не пересоздаются.
- **Живой диктор:** файл `tts/human/<ключ>.ogg` (или `.wav`) заменяет синтез при следующей сборке. Ключ фразы —
  в `tts/out/phrases.json`. Игровые компоненты не меняются.
- Манифест `public/voice/manifest.json`: `{version, voice, files: {ключ: путь}}`; версия меняется при каждой сборке.

### 4. Проверка

- `tts/verify_asr.py` — Whisper large-v3-turbo (MIT): пропуски, перепутанные слова, неверные числа, обрывы.
  Ударение, интонацию и тембр не проверяет — только прослушивание.
- Тест генератора: сгенерированная карточка без записи никогда не попадает к ребёнку (`generate.test.ts`).

## Динамические задания

- Озвучивается всё достижимое множество фраз генератора (сиды до насыщения), а не шаблоны со склейкой слов.
- В игре генератор берёт только карточки, у которых есть записи задания и подсказок (`steps.ts`, `voiced`).
  Редкий непокрытый вариант заменяется другой карточкой того же образца — математика та же.
- Синтез речи устройства в детском режиме **не используется** (раньше на Android им читалась треть карточек).
  Фраза без записи пропускается молча (текст на экране) и попадает в `missingPhrases()` и отчёт.

## Звуковой движок (`src/audio/voice.ts`)

- Одна фраза за раз: новая останавливает предыдущую; очередь `speakAll()` с паузой между фразами.
- `speak()` завершается по реальному окончанию записи, остановке или ошибке файла. Плеер миссии ждёт похвалу
  (не меньше 0,7 с, не больше 2,5 с), а не фиксированные 1600 мс; без звука игра идёт сама.
- `VOICE_STARTED` / `VOICE_FINISHED` → Счётик говорит, пока звучит голос.
- Громкость, отключение голоса и звуков — в «Для взрослых → Анимации и звук». На Android при сворачивании
  речь останавливается.

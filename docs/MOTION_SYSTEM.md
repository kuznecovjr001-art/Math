# Система движения «Считалочки»

## Архитектура

```
игра / экран ──emit()──▶ motion/events.ts (типизированные события) ──▶ подписчики
                                                     ├─ motion/character.ts → Schetik.tsx (состояние Счётика)
                                                     └─ (звуки, аналитика, тесты)
audio/voice.ts ──VOICE_STARTED / VOICE_FINISHED──▶ events
```

| Файл | Что делает |
| --- | --- |
| `src/motion/events.ts` | События `TASK_STARTED`, `VOICE_STARTED`, `VOICE_FINISHED`, `OBJECT_PICKED`, `OBJECT_DROPPED`, `ANSWER_CORRECT`, `ANSWER_INCORRECT`, `HELP_REQUESTED`, `MISSION_COMPLETED`, `STICKER_AWARDED`, `TICK`. Простая шина `emit` / `onGameEvent`. |
| `src/motion/character.ts` | Чистая функция `characterStep(state, event, now)`: состояние Счётика с приоритетами, длительностью реакции и возвратом в базовое. Тесты — `character.test.ts`. |
| `src/motion/Schetik.tsx` | Рисует Счётика по состоянию: смена поз прозрачностью + небольшое движение фигуры. Ход времени — раз в 0,5 с, только когда экран виден. |
| `src/motion/motion.css` | Временные токены, анимации Счётика и карты, уровни движения. |
| `src/motion/tokens.ts` | Те же токены для Web Animations API. |
| `src/settings.ts` | Уровень анимаций, фон, параллакс, праздник (отдельно от прогресса). |

### Состояния Счётика

| Состояние | Когда | Приоритет / длительность | Поза | Движение |
| --- | --- | --- | --- | --- |
| idle | вне задания | базовое | idle | дыхание 4 с |
| greeting | первая карточка миссии | 2 / 1,5 с | idle | прыжок |
| listening | задание идёт, ребёнок действует | базовое | idle | дыхание |
| speaking | звучит голос | базовое, пока звучит | talk | лёгкое покачивание 0,9 с |
| thinking | 20 с без действий | базовое | think | наклон −4° |
| sleeping | 90 с без действий | базовое | idle | медленное дыхание, «z» |
| helping / pointing | подсказка / предмет мимо цели | 3 / 2,5 с; 2 / 1,2 с | help | сдвиг к заданию |
| happy | верный ответ | 4 / 1,2 с (шаг карточки 0,7 с) | happy | прыжок с пружиной |
| encourage | ошибка | 3 / 1,4 с | think | кивок |
| celebrating | конец миссии, наклейка | 5 / 2,5 с | happy | два прыжка |

Более важная реакция не перебивается менее важной; голос во время радости не отменяет её — Счётик «договаривает»
после. Любое касание будит из сна. Все переходы детерминированы и проверяются тестами без браузера.

### Временные токены (стартовые, уточняются на устройствах)

| Токен | Значение | Для чего |
| --- | --- | --- |
| `--dur-press` | 110 мс | отклик кнопки |
| `--dur-appear` | 240 мс | появление элемента |
| `--dur-step` | 350 мс | переход, сдвиг |
| `--dur-joy` | 700 мс | радость |
| `--ease-spring` | cubic-bezier(.34,1.56,.64,1) | мягкая пружина |

Двигаются только `transform` и `opacity`; фильтры и изменения геометрии в анимациях не используются.

### Уровни движения

- Системное «Убрать анимацию» (`prefers-reduced-motion`) отключает всё (styles.css) — главнее настроек.
- `html[data-motion=full]` — всё; `moderate` — без постоянных фоновых циклов (дыхание, облака);
  `minimal` — только смена поз и состояний, без движения.
- `data-ambient=false` — без облаков; `data-parallax=false` — без сдвига фона при прокрутке.

### Синхронизация с голосом

Плеер миссии не ждёт фиксированные 1600 мс: после верного ответа ответ разблокируется, когда похвала
договорена, но не раньше 0,7 с (видна радость) и не позже 2,5 с (без звука, без записи, при сбое игра идёт сама).
Игровая логика от окончания аудио не зависит.

## Что сделано на карте

- Новая открывшаяся миссия плавно «проявляется» один раз; только что пройденная получает звёздочку с пружиной.
- Две мягкие тени облаков медленно плывут над морем (80–110 с); камни миссий не двигаются.
- Лёгкий параллакс морского фона при прокрутке (scroll-driven animation, без JS). Фон карт островов не
  сдвигается: камни стоят на нарисованных площадках, и сдвиг фона увёл бы их с мест.

## ТЗ на слои Счётика (нужно для настоящей персонажной анимации)

Сейчас есть только пять плоских растровых поз 256×256 (`src/assets/art/char/guide-*.webp`). Из них нельзя честно
сделать моргание, движение рта и лап: фигура меняет позу целиком и слегка двигается как одно целое.
Для 2D-рига (SVG с группами или Rive) нужен исходник «Счётик» в той же стилистике:

- **Формат:** SVG (каждая часть — отдельная группа `<g id="…">`) или PSD/Krita с теми же слоями; при Rive — `.riv`
  с костями и состояниями ниже. Холст 1024×1024, персонаж по центру, стоит на линии y = 960.
- **Слои (снизу вверх):** `shell` (панцирь), `body`, `leg-l`, `leg-r`, `arm-l`, `arm-r` (отдельно кисть `hand-l/r`
  для указания), `bag` (сумка), `scarf` (платок, 2 кадра развевания), `head`, `eye-l`, `eye-r` (открытые),
  `lid-l`, `lid-r` (веки: открыты, полузакрыты, закрыты), `brow-l/r`, `mouth` (5 форм: закрыт, улыбка, «а», «о», «у»),
  `cheek-l/r`.
- **Точки крепления (pivot):** голова — основание шеи; руки — плечо; кисти — запястье; ноги — бедро;
  веки — верх глазного яблока; платок — узел.
- **Состояния для проверки рига:** idle (дыхание, моргание каждые 3–6 с), greeting (взмах правой лапкой 2 раза),
  listening (голова к заданию), thinking (наклон головы, лапка у подбородка), speaking (рот по формам),
  helping/pointing (правая лапка вперёд), happy (лапки вверх), encourage (кивок, мягкая улыбка),
  celebrating (подпрыгивание, лапки вверх), sleeping (веки закрыты, медленное дыхание).
- **Экспорт:** SVG без растров внутри, без фильтров и масок размытия; цвета — плоские заливки; в Rive — состояние
  через input `mood` (строка из списка выше) и trigger `blink`.
- Пока слоёв нет, `Schetik.tsx` работает на пяти позах; при появлении рига меняется только этот компонент.

## Чего нет и почему

- Сон и приветствие не имеют своих рисунков — используется поза idle (см. ТЗ на слои).
- Вода и деревья островов не двигаются: фоны — единые растры без отдельных слоёв воды/крон. Для этого нужны
  отдельные PNG-слои (маска воды, кроны деревьев) по сетке фона; без них движение пришлось бы делать по всему
  фону, а это запрещено (сдвигались бы площадки миссий).

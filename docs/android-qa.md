# Проверки Android

## Как повторить

1. Собрать и поставить debug-APK (эмулятор или телефон взрослого, **не** телефон ребёнка — данные заменяются):
   `npm run build && npx cap sync android && cd android && gradlew assembleDebug`,
   `adb install -r app/build/outputs/apk/debug/app-debug.apk`, запустить приложение.
2. `npx vite-node scripts/android-smoke.ts -- <имя-прогона>` — открывает каждую из 49 миссий с карты в настоящем
   Android WebView, проверяет горизонтальную прокрутку, элементы за краем экрана, цели касания < 44 CSS px и
   сохраняет снимки + `report.md` в `.qa/android/<имя-прогона>/` (папка в `.gitignore`).

Также проверено на эмуляторе (вручную через adb):

- Холодный старт в авиарежиме: экран профилей за ~0,7–1,7 с, сеть не нужна. — PASS
- Создание профиля, карта, вход в миссию. — PASS
- Аппаратная «Назад»: миссия → карта → профили → приложение сворачивается (не закрывается). — PASS
- Закрытие процесса (`am force-stop`) и запуск: профиль, 49 попыток и заходы на месте. — PASS
- Service worker в Android не регистрируется (ресурсы внутри APK). — PASS
- Итоговый манифест: единственное разрешение — внутреннее `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`
  (androidx, уровень signature); `INTERNET` удалён. minSdk 26 (Android 8.0), targetSdk 36. — PASS
- `gradlew lintDebug`: 0 ошибок; предупреждения — устаревшие версии библиотек шаблона, неиспользуемые ресурсы
  шаблона, нет монохромной иконки (Android 13+ тематические иконки), фиксация ориентации (намеренно, только телефоны).

## Не проверено (BLOCKED_MANUAL)

- Физические устройства: слабый телефон на Android 8–9, планшет, настоящий звук и касания пальцем.
- Озвучка на устройстве (в эмуляторе без звука), синтез речи WebView без записей.
- Крупный шрифт системы, TalkBack.
- «Сохранить копию» через системное меню «Поделиться» и восстановление из файла на устройстве.
- Перетаскивание пальцем (смоук нажимает только кнопки).

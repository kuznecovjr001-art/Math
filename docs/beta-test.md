# Бесплатное тестирование «Считалочки»

Как выпустить версию для семей-тестировщиков в RuStore и что у них спросить. Публикацию делает только владелец.
Порядок действий сверен со справкой RuStore 2026-11-01: перед загрузкой посмотрите, не изменились ли названия разделов.

## Что сделать владельцу

В RuStore публичный тест называется бета-тестированием. Он доступен только приложению с опубликованной основной версией,
поэтому порядок такой: сначала основная версия 1.0.0, затем бета. Загруженный APK заменить нельзя: для каждой новой
загрузки нужен больший `versionCode`.

### 1. Подготовка на компьютере

1. **Проверить сборку на планшете:** debug-APK `Schitalochka-2026-11-02-test.apk` из «Загрузок», по 2–3 миссии на остров.
2. **Подтвердить `appId`** `io.github.kuznecovjr001_art.schitalochka`: после первой загрузки он не меняется.
3. **Собрать подписанный APK** у себя в терминале. При первом запуске скрипт создаст ключ:

   ```bash
   powershell -ExecutionPolicy Bypass -File scripts\release-apk.ps1
   ```

   Пароль придумайте сами и введите только в терминале: дважды для нового ключа и один раз для сборки.
   Результат: `Загрузки\Schitalochka-release.apk`.
4. **Сохранить ключ:** файл `schitalochka-keys\schitalochka-release.jks` и пароль минимум в двух местах. Без них обновления
   выпустить нельзя. Никому их не передавайте, в том числе в чат.
5. **Опубликовать политику:** слить изменения в `main` и открыть
   `https://kuznecovjr001-art.github.io/Math/privacy.html`.

### 2. Основная версия в RuStore Консоли

1. Войти в [RuStore Консоль](https://console.rustore.ru) через VK ID, оформить профиль разработчика. Приложение может
   добавить только роль «Владелец компании».
2. «Приложения» → «Добавить приложение» → название «Считалочка» → «Добавить».
3. «Загрузить версию», тип «Универсальный», файл `Schitalochka-release.apk`. Страницу не закрывать, пока файл загружается.
4. Заполнить поля из `docs/store-listing.md`: «Что нового?», название, категория, возраст 0+, теги, описания.
5. «Безопасность данных пользователя»: приложение данные не собирает, чувствительных разрешений нет.
6. «Способы связи»: почта и МАКС из `docs/store-listing.md`.
7. Медиафайлы: иконка `public/app-icon-512.png`, снимки `docs/store/phone-*.jpg` и `docs/store/tablet-*.jpg`.
8. «Отправить на модерацию». Обработанный файл хранится 14 дней. После одобрения приложение доступно всем в каталоге.

### 3. Публичный тест (бета)

1. Поднять `versionCode` до 2 и `versionName` до 1.0.1 в `android/app/build.gradle`, закоммитить, снова запустить
   `scripts/release-apk.ps1`.
2. Приложение → «Тестирование» → «Бета-тестирование» → «Загрузить». Загрузить новый APK, заполнить описание обновления и
   безопасность данных, «Отправить на модерацию».
3. Статус «Готова к тестированию» → «Начать тестирование».
4. Скопировать ссылку в Консоли и разослать. Участвовать может любой, у кого есть ссылка; бета также видна в карточке
   приложения со значком β. Нужен RuStore 1.80 или новее.
5. Завершение: «Перенести в релизную версию» или «Снять с тестирования без публикации». Отзывы по бете не влияют на рейтинг.

Если нужен закрытый тест до публикации: «Тестирование» → «Альфа-тестирование» → «Альфа-версии» → «Загрузить версию», затем
«Тестировщики» → «Пригласить тестировщика» по VK ID (до 2000 человек). Альфа работает только в мобильном приложении RuStore.

Справка сверена 2026-11-02:
[бета](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/testing/beta-testing),
[альфа](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/testing/alpha-testing),
[публикация](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication).
Отдельного поля для ссылки на политику в описании шагов нет: политика открывается в приложении, а ссылку можно добавить
в конец подробного описания.

Размер APK около 200 МБ укладывается в лимит RuStore (русская справка: до 5 ГБ).

## Сообщение для тестировщиков

> Привет! Мы делаем «Считалочку»: математику для детей 4–9 лет. Приложение бесплатное, без рекламы и покупок, работает
> без интернета и не собирает данные. Поможете проверить его с ребёнком?
>
> 1. Откройте ссылку на телефоне или планшете: [ссылка из RuStore].
> 2. Установите приложение (около 200 МБ, лучше по Wi-Fi).
> 3. Дайте ребёнку позаниматься 10–15 минут несколько дней подряд. Не подсказывайте сразу: нам важно увидеть, где он
>    застрянет.
> 4. Ответьте на вопросы ниже в удобном виде: можно голосовым сообщением.
>
> Спасибо!

## Вопросы родителям

1. Сколько лет ребёнку, какое устройство и какая версия Android?
2. Понял ли ребёнок без вас, что делать в первой миссии?
3. Где застрял или расстроился? Какая миссия, что было на экране?
4. Были ли задания слишком лёгкие или слишком трудные? Какие?
5. Слышно ли голос, все ли слова звучат правильно? Какие слова с неверным ударением?
6. Было ли что-то резкое, дёрганое, зависало или закрывалось само?
7. Хотел ли ребёнок вернуться на следующий день?
8. Понятен ли вам отчёт в разделе «Для взрослых»? Чего в нём не хватает?

Не просите присылать имя, фото или видео ребёнка: приложение таких данных не собирает, и тесту они не нужны.

## Что смотреть в ответах

| Сигнал | Что делать |
| --- | --- |
| Падение, зависание, нет звука | исправить до следующей версии, повторить проверку на этом устройстве |
| Трое и больше детей застряли в одной миссии | пересмотреть подсказки и сложность миссии |
| Неверное ударение | добавить слово в `tts/stress.json`, перезаписать затронутые фразы |
| Вопросы о данных | ответить по `public/privacy.html` |

Каждая новая загрузка: `versionCode` в `android/app/build.gradle` больше прежнего, тот же ключ подписи.

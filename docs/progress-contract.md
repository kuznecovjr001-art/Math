# Контракт учебных данных и метрик

Хранилище: `localStorage['mathkids:v1']`, формат `AppData` (`src/engine/types.ts`), `version: 1`.
Все новые поля необязательны: записи прошлой версии читаются без миграции, прошлая версия читает новые.

## События

| Событие | Где хранится | Когда пишется |
| --- | --- | --- |
| Заход в миссию | `sessions[]`: `id`, `profileId`, `missionId`, `mode` (`play`/`review`/`again`), `assigned?`, `startedAt`, `cards`, `shown`, `finishedAt?` | при старте, на каждой новой карточке, в конце |
| Показ карточки | `sessions[].shown` — сколько карточек ребёнок увидел в заходе | вместе с заходом |
| Ответ (попытка) | `attempts[]`: `sessionId`, `step` (номер карточки в заходе), `errorsBefore`, `partial?`, `helpLevel`, `mode`, `variant`, `correct`, `answer`, `at` | на каждое нажатие «ответить» (повторное нажатие во время реакции блокируется) |
| Завершение миссии | `stickers[profileId]` (наклейка) и `sessions[].finishedAt` | ребёнок дошёл до последней карточки |

Экземпляр карточки = `sessionId + step`. Промежуточный шаг многошаговой карточки (`final === false` в игре,
например раскладка до вопроса об итоге) пишется с `partial: true` и **не** считается ответом на карточку.

## Определения

- **Самостоятельный успех** (`isIndependentSuccess`): верно, `helpLevel = 0`, не обучение (`mode ≠ learn`),
  не промежуточный шаг, `errorsBefore = 0` (с первого раза). Верный ответ после ошибки не самостоятельный:
  при трёх вариантах ответа перебор даёт «верно» на второй попытке.
- **Итог карточки** (`cardOutcomes`): `learning` (карточка обучения) · `independent` (решена с первого раза
  без помощи) · `afterError` (решена без помощи после ошибки) · `withHelp` (решена с помощью) · `unsolved`
  (ребёнок не дошёл до верного итога).
- **Открытие следующей миссии** (`probeReached`): ребёнок дошёл до самостоятельной пробы. Это авторское правило
  пути (не задерживать ребёнка), а не завершение и не освоение.
- **Миссия завершена**: есть наклейка (дошёл до конца захода).
- **Статус навыка** (`skillStatus`): знакомится → с помощью → есть самостоятельный успех → уверенно
  (≥ 3 самостоятельных успеха в ≥ 2 разных дня) → подтверждено (самостоятельный успех в повторе спустя
  ≥ 3 дня после первого). Пороги — настройки пилота.
- **Пора повторить** (`reviewDueAt`): 1, 3, 7, 14 дней после последнего самостоятельного успеха.

## Метрики родителя (`summarize`, период — целые календарные дни)

- Знаменатель долей — `tried`: карточки с ответом, без обучения.
- `independent / tried`, `afterError / tried`, `withHelp / tried`, `unsolved / tried`.
- Если `tried < 10` (`MIN_SAMPLE`), проценты не показываются: только числа и «мало данных».
- Нет сравнений с другими детьми, нормами возраста и диагнозов. Не сыгранная миссия ≠ непонятый навык.

## Старые записи (до 2026-10)

У них нет `sessionId/step/errorsBefore/partial`: каждая попытка считается отдельной карточкой,
`errorsBefore` неизвестен (как раньше, успех без помощи — самостоятельный), промежуточные шаги не отмечены.
Поэтому старая история может немного завышать самостоятельность; новые заходы считаются точно.
Показы карточек в старых записях неизвестны (`shown = 0`).

# Математика для детей

Веб-приложение (PWA) для изучения основ математики детьми 4–6 лет, позже — начальная школа.
Работает в любом браузере: телефон, планшет, компьютер. Код пишется с нуля.

## Стек
- React 19 + TypeScript + Vite 6.
- PWA на своём service worker: `public/sw.js` + manifest (без vite-plugin-pwa).
- Тесты: Vitest. Playwright для сценариев в браузере — в планах.
- Команды запуска — в `README.md`.

## Структура
- `src/engine` — прогресс и статусы навыков, чистый TypeScript, покрыт тестами.
- `src/content` — навыки M01–M14 и миссии.
- `src/games` — по компоненту на миссию.
- `src/screens` — экраны приложения.
- `public/img/openmoji` — картинки OpenMoji (CC BY-SA, указывать авторство).

## Правила для детского продукта
- Никаких таймеров, «жизней», штрафов и рекламы. Ошибка — это подсказка, а не наказание.
- Крупные цели касания (не меньше 48×48 px), минимум текста, озвучка и картинки вместо чтения.
- Интерфейс на русском языке. Все тексты — в одном месте (словарь), не разбросаны по компонентам.
- Никаких сборов персональных данных детей, внешних трекеров и сторонних скриптов.
- Доступность: контраст WCAG 2.2 AA, работа без звука, уважение `prefers-reduced-motion`.
- Производительность: быстрый первый экран на слабом телефоне, проверка через Lighthouse.

## Как работаем
- Новая фича: `/feature-dev` (исследование → архитектура → реализация → ревью).
- Перед кодом — короткий план; логику заданий покрываем тестами (подход TDD из superpowers).
- UI: скиллы `frontend-design` и `ui-ux-pro-max` для стиля, палитры и шрифтов.
- Перед PR: аудит из `web-quality-skills` (доступность, Core Web Vitals, SEO).
- `security-guidance` подсказывает о рисках при правке кода.
- Ветка на каждую задачу, изменения — через PR.

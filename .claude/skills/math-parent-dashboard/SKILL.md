# math-parent-dashboard

1. Главный экран: профиль, последнее занятие, освоенные/требующие повторения навыки, карточка плана и явная ссылка на историю.
2. Графики 7/30 дней; отдельные показатели ошибок/подсказок и самостоятельных успехов, объяснения метрик понятным русским языком.
3. Исключить рейтинги детей, диагнозы, манипулятивные streaks и сравнения с другими детьми.
4. Управление назначениями и изменениями требований — только за parent gate.
5. Проверить доступность таблиц и графиков текстовой альтернативой.

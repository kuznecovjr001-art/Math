# math-motion-rules

1. Сначала описать состояния и события, только после добавлять библиотеку.
2. CSS transitions для простых контролов, Motion React для переходов/жестов, Rive только при обоснованном необходимости и наличии исходников/лицензии.
3. Анимации касаний ориентир 100–180ms, feedback 200–450ms; крупные награды до ~900ms; параметры менять после тестов на устройстве.
4. Анимировать transform/opacity, не создавать постоянную графическую нагрузку, реакция должна отвечать учебной семантике.
5. `prefers-reduced-motion` отключает декоративные движения, остаётся статичная ясная обратная связь. Тестировать no-sound.

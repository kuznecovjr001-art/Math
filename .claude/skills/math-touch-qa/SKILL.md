# math-touch-qa

1. Проверить portrait 360×800, 390×844 и планшет 800×1280 / 1280×800, также 320×568 для стресс-теста.
2. У основных интерактивных областей комфортный размер для ребёнка, нет горизонтального скролла, обрезания цифр и наложения на ОС-навигацию.
3. Тап, drag, drop, отмена, двойной тап, медленный жест, случайное перемещение; предложить alternative controls.
4. Проверить 49 миссий как smoke, ключевые 10–15 как глубокий E2E. Не подменять реальное устройство браузерной эмуляцией.
5. Документы: screenshots, defect register, coverage table.

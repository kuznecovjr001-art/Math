# math-pedagogy-audit

1. Для каждой из 49 миссий выпиши цель, навыки,Prerequisites, возрастной диапазон, варианты A/B/C, диапазоны чисел и конкретный ожидаемый результат.
2. Проверь 40+ фиксированных seed для каждого режима; тестируй уникальность вариантов и наличие верного ответа, ошибки в словесной постановке.
3. Проверь корректность математической терминологии и отсутствие противоречий в подсказках разных уровней.
4. Не выводи педагогическую эффективность из unit-тестов; пометь необходимость наблюдения детей/педагога.
5. Результат: таблица аудита по id миссии и тесты на регрессию.

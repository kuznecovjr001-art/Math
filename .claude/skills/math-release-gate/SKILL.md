# math-release-gate

1. Все тесты и детский UX без P0/P1 блокеров, Android 8+ по требованиям RuStore, согласовать фактический minSdk с Capacitor.
2. Проверить стабильность, webview added functionality, offline cold start, декларируемые разрешения, детские данные, возраст, лицензии.
3. Собрать подписанный APK/AAB только после явного выбора signing strategy владельцем; никогда не коммитить keystore.
4. Проверить карточку приложения: описания, иконка, телефонные/планшетные скриншоты, privacy policy, контакты, changelog.
5. Финальный статус GO/NO-GO со ссылками на прогоны и недостающие доказательства. Публикация — действие владельца.
